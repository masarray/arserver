# Search Fields Patch

This patch improves signal navigation in ARServer:

- Replaces the old `Priority: position → protection → measurement` text on the Live IEC 61850 Values card with a compact search field.
- Adds a magnifier icon and quick clear action to the Live IEC 61850 search.
- Upgrades the Wizard signal search into the same premium search pill with magnifier icon and quick clear action.
- Extends search matching to include IEC object reference, logical node, category, data type, FC, current value, quality, timestamp, report plan and report-plan reason.
- Keeps multi-selection workflow in the Wizard: Extended selection, Ctrl/Shift row selection, header checkbox, row checkbox block toggle, Ctrl+A and Space toggle.
