Route validasi

Gunakan ARServer sebagai layer engineering yang transparan

FAT dan SAT butuh evidence. Gateway tidak berguna kalau source value, output value, timestamp, quality, dan communication state tidak bisa dilihat. ARServer membuat check ini terlihat sebelum mapping dipercaya.

Yang perlu divalidasi

  • IED association dan reconnect behavior.
  • Object path dan value IEC 61850 terpilih.
  • Quality, timestamp, stale state, dan diagnostics.
  • Mapping alamat Modbus dan interpretasi HMI.
  • Route MQTT topic dan bentuk payload.

Urutan FAT/SAT yang disarankan

  1. Siapkan jaringan test dan relay/simulator.
  2. Load atau discover model IED.
  3. Pilih hanya point test yang disepakati.
  4. Simulasikan perubahan state jika aman.
  5. Konfirmasi value ARServer, Modbus value, dan MQTT payload.
  6. Catat exception sebelum test list diperluas.
Batasan: ARServer bukan protection injection test set. Gunakan sebagai alat visibility, mapping, dan validasi gateway data path.
