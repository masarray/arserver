Use case HMI / SCADA

Expose data relay IEC 61850 terpilih sebagai point Modbus TCP yang stabil.

Use case ini cocok untuk tim yang HMI, SCADA, atau DCS-nya lebih mudah membaca Modbus TCP daripada IEC 61850 MMS langsung.

Route integrasi

Relay / IED → ARServer → Modbus TCP → HMI/SCADA

ARServer membaca nilai IEC 61850 terpilih dari relay, menyimpannya di runtime cache, lalu expose point mapping melalui Modbus TCP server. HMI atau SCADA polling ARServer tanpa perlu berbicara IEC 61850 langsung.

Signal awal yang paling masuk akal

  • Posisi breaker atau switch.
  • Start, trip, dan operation indication proteksi.
  • Alarm utama dan status equipment.
  • Measurement dengan scaling dan unit yang jelas.

Yang wajib didokumentasikan

Setiap point Modbus perlu address, tipe data, scale, arti Boolean, source IEC object, quality behavior, stale behavior, dan interpretasi HMI yang diharapkan.

Jangan handover hanya nomor register. Modbus map tanpa source object, quality handling, dan stale behavior bukan deliverable engineering yang aman.

Checklist acceptance

  1. Komunikasi IED stabil di jaringan test.
  2. Object IEC terpilih terbaca benar.
  3. Modbus client bisa polling semua point mapping.
  4. HMI menampilkan arti dan scaling yang benar.
  5. Communication loss menghasilkan stale atau diagnostic state yang terlihat.
