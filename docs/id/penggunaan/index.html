Pusat use case

Pilih workflow ARServer sesuai masalah engineering yang ingin diselesaikan.

ARServer berguna ketika data relay IEC 61850 perlu dikonsumsi oleh sistem yang lebih mudah memakai Modbus TCP atau MQTT. Halaman ini membantu user memilih jalur sebelum mulai konfigurasi.

Kesesuaian produk

Di mana ARServer paling tepat dipakai

ARServer bukan relay test set penuh. ARServer adalah gateway dan workspace engineering untuk membaca nilai IEC 61850 MMS terpilih, memvalidasi, lalu menerbitkannya ke sistem pemakai data.

Use case awal terbaik: mulai dari satu relay atau simulator, pilih sedikit point penting, validasi source value, lalu expose ke satu Modbus client atau satu MQTT broker.
Integrasi HMI/SCADABridge nilai IED IEC 61850 ke register Modbus TCP yang stabil untuk HMI, SCADA, atau DCS.FAT/SAT relay benchGunakan ARServer sebagai layer visibility saat lab, FAT, SAT, dan validasi point-to-point.MQTT dashboardPublish nilai relay dengan quality dan timestamp ke dashboard, middleware, atau historian.Mulai dari nolIkuti route praktis dari persiapan network sampai gateway berjalan.

Cara memilih

  • Pilih HMI/SCADA jika sistem pemakai data membutuhkan Modbus TCP.
  • Pilih FAT/SAT jika fokusnya validasi, evidence, dan pembacaan saat test.
  • Pilih MQTT Dashboard jika sistem pemakai data berbasis broker.
