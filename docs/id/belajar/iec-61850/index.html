Dasar IEC 61850

IEC 61850 adalah model data relay, bukan sekadar port komunikasi.

Untuk pengguna ARServer, IEC 61850 adalah sisi sumber. Relay atau IED menampilkan objek listrik yang punya value, quality, dan timestamp. ARServer membaca point terpilih lalu menerbitkannya ke interface yang lebih mudah dipakai.

Hal yang perlu dipahami sebelum membaca data relay

IEC 61850 banyak dipakai di otomasi gardu karena mendeskripsikan fungsi peralatan secara terstruktur. Relay tidak diperlakukan sebagai daftar angka mentah, tetapi sebagai model berisi logical device, logical node, data object, dan data attribute.

Istilah inti

  • IED: relay, bay controller, meter, atau intelligent electronic device.
  • Logical node: blok fungsi seperti XCBR untuk circuit breaker, PTOC untuk proteksi arus lebih, atau MMXU untuk measurement.
  • Data object: objek di dalam logical node, misalnya Pos, Op, atau A.
  • Data attribute: atribut yang dibaca, misalnya stVal, q, atau t.
  • Function constraint: pengelompokan status, measurement, control, konfigurasi, atau deskripsi.

Kenapa MMS penting

Dalam workflow ARServer, IED dibaca melalui IEC 61850 MMS. MMS memberi akses ke object reference bernama, bukan sekadar alamat angka. Ini kuat untuk engineering, tetapi tidak selalu mudah untuk HMI/SCADA biasa.

Kenapa file SCL membantu

File SCL seperti ICD, CID, IID, dan SCD mendeskripsikan model engineering IED. Jika tersedia, file ini membantu user merencanakan object reference dan signal yang akan dipilih sebelum konek ke device live.

Aturan lapangan: jangan mapping semua point IEC 61850. Mulai dari posisi breaker, start/trip proteksi, alarm, mode/status, dan measurement penting. Validasi value, quality, dan timestamp sebelum diberikan ke HMI.
