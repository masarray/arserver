Belajar protokol untuk pengguna ARServer

ARServer berada di antara relay/IED dan sistem yang membutuhkan data yang mudah dibaca. Sisi sumber adalah IEC 61850 MMS. Output klasiknya adalah Modbus TCP. Output data modernnya adalah MQTT.

Model sederhana: IEC 61850 membaca model relay. ARServer memilih dan memvalidasi point penting. Modbus TCP dan MQTT membuat point tersebut mudah digunakan oleh HMI, SCADA, dashboard, atau middleware.

Urutan belajar yang disarankan

  1. Pahami istilah IEC 61850: IED, logical node, data object, data attribute, function constraint, quality, timestamp, dan SCL.
  2. Pahami cara berpikir Modbus TCP: register, polling client, discrete input, input register, dan address planning.
  3. Pahami MQTT: broker, topic, payload, retain, quality context, dan timestamp context.
  4. Gunakan Quick Start ARServer untuk tambah relay atau SCL file, pilih signal, validasi, mapping, lalu jalankan gateway.
