Dasar Modbus TCP

Modbus TCP adalah bahasa praktis yang sudah dipahami banyak HMI dan SCADA.

Untuk pengguna ARServer, Modbus TCP adalah interface konsumsi data. Ia tidak menggantikan IEC 61850, tetapi membuat nilai relay terpilih lebih mudah dipolling oleh HMI, SCADA, DCS, dan test client.

Makna Modbus TCP dalam workflow ARServer

Modbus TCP sederhana: client polling server untuk membaca bit dan register. Karena sederhana, banyak HMI/SCADA dapat membaca Modbus meskipun tidak bisa membaca IEC 61850 langsung.

Area data utama

  • Coils: Boolean output dalam istilah Modbus klasik.
  • Discrete inputs: Boolean status read-only.
  • Input registers: nilai numerik read-only.
  • Holding registers: register numerik yang sering dipakai untuk data konfigurasi atau data yang bisa ditulis.

Kenapa address planning penting

Modbus tidak membawa nama kaya seperti XCBR1.Pos.stVal. Arti alamat 30001 berasal dari dokumen mapping. Karena itu map harus stabil, rapi, dan mudah diaudit.

Prinsip ARServer: mapping hanya point IEC 61850 yang terpilih dan sudah divalidasi. Register map harus cukup kecil untuk diaudit dan cukup stabil untuk engineer HMI.
